# Number Ten: The Maze

A first-person 3D horror maze game that runs in your web browser. No install needed.

You're lost in a maze with **Number Ten**, a blind creature that hunts by sound. Find the 3 spear shards, strike it 3 times, then escape through the exit. Your friend **Finn #150** follows you, gives you directions and warns you when it's close.

## Play

Open `index.html` in a browser, or play it online through GitHub Pages (see below).

## Levels

- **Jungle**: hedge walls, trees, fireflies and jungle sounds at night
- **Backrooms**: endless yellow rooms, buzzing lights and power cuts
- **Gym maze**: dark tunnels under the old gym

## How to play

- Number Ten is blind, but it hears everything. Running is loud, walking is quieter, sneaking and standing still are silent.
- Find the 3 spear shards, then sneak up and strike it 3 times.
- When it dies, the exit opens. Follow the light out.
- If it catches you, you can get back up and keep your shards and spear.

## Controls

| Action | Keyboard | Phone |
| --- | --- | --- |
| Move | WASD or arrow keys | Left side of the screen |
| Look | Mouse (click the view) or Q / E | Drag on the view |
| Run | Shift | RUN |
| Sneak | Hold Ctrl or C | SNEAK |
| Strike | Space or F | STRIKE |
| Flashlight | L | LIGHT |
| Ask Finn for help | T | TALK |
| Map | M | MAP |

## Put it online with GitHub Pages

1. In this repository, go to **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**.
3. Pick the **main** branch and the **/ (root)** folder, then **Save**.
4. After a minute your game is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
